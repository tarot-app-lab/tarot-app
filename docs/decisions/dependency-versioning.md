# Decision: Dependency Versioning

## Status

Accepted for active development.

## Decision

В `package.json` не используем `latest`.

Версии зависимостей фиксируются конкретными значениями, совпадающими с `package-lock.json`.

## Why

- Разработчики должны получать одинаковое окружение на разных машинах.
- CI должен проверять тот же dependency graph, что и локальная разработка.
- Неожиданные major/minor обновления не должны попадать в проект без отдельного review.

## Process

- Для восстановления окружения использовать `npm ci`.
- Для обновления зависимости создавать отдельную задачу или PR.
- Перед обновлением объяснять, зачем нужна новая версия и какие риски она несет.
