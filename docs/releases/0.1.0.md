# Release 0.1.0 — MVP

## Goal

Собрать первый offline-first MVP Tarot App для iOS и Android.

## Scope

- Onboarding
- Cards list
- Card details
- Card of the day
- Basic spreads
- Reading result
- Reading history
- Settings
- Local SQLite storage

## Out of Scope

- Backend
- Accounts
- Cloud sync
- Web app
- Subscriptions
- AI interpretations
- Push notifications

## Release Criteria

- App запускается на iOS и Android
- Все MVP-экраны доступны
- Приложение работает без интернета
- Данные карт доступны локально
- История раскладов сохраняется локально
- TypeScript проходит
- Jest проходит
- Smoke test пройден вручную
