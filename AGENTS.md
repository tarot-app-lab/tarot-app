# AGENTS.md

## Rules

- Do not push directly to main.
- Work only in separate branches.
- Every change must go through Pull Request.
- Keep changes small.
- Do not rewrite unrelated files.
- Do not add new libraries without approval.
- Always run tests before final answer.
- Never commit secrets, tokens, API keys, or passwords.

## Branch names

- feature/leo-task-name
- feature/alex-task-name
- fix/task-name

## Pull Request checklist

- What was changed?
- Why was it changed?
- How was it tested?
- What risks are known?
